EXECUTIVE SUMMARY
================================================================================

ERROR: "The selected status is invalid" appears when trying to save Sales or 
       Gudang records with status selection.

ROOT CAUSE: Frontend sends Indonesian status values ('aktif'/'nonaktif') but 
            backend validation expects English values ('active'/'inactive').

SEVERITY: High - Blocks core functionality (Sales & Gudang master data management)

SCOPE AFFECTED:
  - Sales Rep creation/update
  - Warehouse (Gudang) creation/update

================================================================================

================================================================================

1. BACKEND VALIDATION (CORRECT)
   ✓ SalesRepController validates: 'in:active,inactive'
   ✓ WarehouseController validates: 'in:active,inactive'
   ✓ Database enums defined as: ['active', 'inactive']
   ✓ All database records store: 'active' or 'inactive'

2. FRONTEND SENDING (WRONG)
   ✗ Sales.tsx sends: status = 'aktif' (Indonesian)
   ✗ Gudang.tsx sends: status = 'aktif' (Indonesian)
   ✗ Types define: 'aktif' | 'nonaktif' (Indonesian)
   ✗ No transformation layer in API hooks

3. MISMATCH SUMMARY
   Frontend UI: Indonesian ("Aktif" / "Nonaktif")
   Frontend Code: Indonesian ('aktif' / 'nonaktif')
   Backend API: English ('active' / 'inactive')
   Database: English (ENUM values)
